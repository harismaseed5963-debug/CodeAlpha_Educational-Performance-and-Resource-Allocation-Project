# CodeAlpha_Educational-Performance-and-Resource-Allocation-Project

# 📌 Project Overview

The Educational Performance & Resource Allocation Dashboard is a Power BI project developed as part of the CodeAlpha Power BI Internship.

The purpose of this project is to transform raw educational data into meaningful insights that help educators, school administrators, and policymakers understand the factors affecting student performance while evaluating how educational resources influence academic outcomes.

Rather than relying on assumptions, this dashboard enables data-driven decision-making by presenting interactive visualizations that highlight trends, comparisons, and performance indicators across multiple educational dimensions.

# 🎯 Problem Statement

Educational institutions often struggle to answer questions such as:

Which factors most influence student performance?
Are school resources being utilized effectively?
Does attendance significantly impact exam scores?
How does parental involvement affect learning outcomes?
Are students receiving equal educational opportunities?
Which areas require improvement to increase academic success?

Without proper analytics, these decisions are frequently based on intuition instead of evidence.

This dashboard addresses these challenges by converting educational data into actionable insights.

# 🚀 Objectives

Analyze overall student academic performance.
Evaluate attendance and its relationship with exam scores.
Assess the impact of school resources on student outcomes.
Compare performance across school types.
Measure the influence of parental involvement.
Analyze the effect of internet accessibility.
Understand how teacher quality contributes to academic achievement.
Support evidence-based educational planning.

# 📊 Dashboard Features

The dashboard includes interactive visualizations for:

Total Students,
Average Exam Score,
Average Previous Scores,
Average Attendance,
Exam Score by School Type,
Exam Score by Resource Availability,
Attendance vs Exam Score by Gender,
Exam Score by Parental Involvement,
Exam Score by Internet Access,
Extracurricular Activity Distribution,
Gender-wise Performance Analysis,
Dynamic Filters and Slicers
